Every request to the ScaleStack API must include your API key as a Bearer token in the `Authorization` header. Your API key is scoped to your organization — all requests you make with it act on behalf of that organization's data and resources.

## Find your API key

Sign in to your ScaleStack account and navigate to **Organization Settings**. Your API key is listed under the **API** section. Copy it and store it somewhere secure — treat it like a password.

<Warning>
  Do not expose your API key in client-side code, public repositories, or logs. Anyone with your key can make API calls on behalf of your organization.
</Warning>

## Add the authorization header

Include your API key in every request using the `Authorization` header:

```
Authorization: Bearer <your_api_key>
```

### Example request

The following example calls `GET /users/` to verify your credentials and retrieve your current user information:

<CodeGroup>

```bash curl
curl https://backend.scalestack.ai/v2/users/ \
  --header "Authorization: Bearer <your_api_key>"
```

```python Python
import requests

response = requests.get(
    "https://backend.scalestack.ai/v2/users/",
    headers={"Authorization": "Bearer <your_api_key>"},
)
print(response.json())
```

```javascript Node.js
const response = await fetch("https://backend.scalestack.ai/v2/users/", {
  headers: {
    Authorization: "Bearer <your_api_key>",
  },
});
const data = await response.json();
console.log(data);
```

</CodeGroup>

A successful response returns your user profile:

```json
{
  "id": "usr_01abc123",
  "email": "you@example.com",
  "organization_id": "org_01xyz456"
}
```

## Authentication errors

If your API key is missing, expired, or invalid, the API returns a `401 Unauthorized` response:

```json
{
  "detail": "Authentication credentials were not provided."
}
```

If you receive a `401`, check that:

- You included the `Authorization` header in the request.
- The header value starts with `Bearer ` followed by your key (note the space).
- You copied the full API key without any leading or trailing whitespace.
- Your API key has not been revoked in **Organization Settings**.

<Note>
  API keys are organization-scoped. If you belong to multiple organizations, make sure you are using the key for the organization whose data you intend to access.
</Note>
