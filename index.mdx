ScaleStack is a platform for building and executing AI-powered data enrichment pipelines. You define workflows made up of composable modules — each one performing a specific enrichment task — and ScaleStack runs them against your datasets at scale. Whether you're enriching prospect lists, cleaning CRM data, or automating research workflows, ScaleStack gives you the tools to do it through a REST API or the product UI.

## Get started in 3 steps

<Steps>
  <Step title="Get your API key">
    Sign in to your ScaleStack account and retrieve your API key from the organization settings. All API requests require this key in the `Authorization` header.
  </Step>
  <Step title="Create a workflow">
    Use the API or UI to define a workflow with one or more enrichment modules. Each module adds a column of enriched data to your input rows.
  </Step>
  <Step title="Execute and retrieve results">
    Send your input data, trigger a workflow run, and poll for status. When the run completes, fetch the enriched output data.
  </Step>
</Steps>
