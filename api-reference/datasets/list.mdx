---
title: "List datasets in an organization"
description: "Retrieve a paginated list of all datasets in your organization, including processing status, row counts, and column counts for each dataset."
---

Use this endpoint to fetch all datasets associated with a given organization. The response includes summary metadata for each dataset — such as its current processing status, row count, and column count — which is useful for building dataset pickers, dashboards, or automations that operate across multiple datasets.

## Path parameters

<ParamField path="org_id" type="string" required>
  The unique identifier for your organization (e.g. `org_abc123`).
</ParamField>

## Query parameters

<ParamField query="page" type="integer">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="page_size" type="integer">
  The number of datasets to return per page. Defaults to `20`. Maximum is `100`.
</ParamField>

## Request

```bash
curl -X GET "https://backend.scalestack.ai/v2/datasets/organizations/org_abc123/" \
  -H "Authorization: Bearer <api_key>"
```

With pagination:

```bash
curl -X GET "https://backend.scalestack.ai/v2/datasets/organizations/org_abc123/?page=2&page_size=50" \
  -H "Authorization: Bearer <api_key>"
```

## Response

Returns an array of `DatasetListItem` objects.

<ResponseField name="id" type="string">
  The internal UUID for the dataset.
</ResponseField>

<ResponseField name="string_id" type="string">
  A human-readable slug identifier for the dataset (e.g. `my-dataset`). Use this in other endpoint paths.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the dataset.
</ResponseField>

<ResponseField name="status" type="string">
  Current processing state of the dataset. One of: `pending`, `ready`, `processing`, or `error`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the dataset was created.
</ResponseField>

<ResponseField name="row_count" type="integer">
  The number of data rows in the dataset.
</ResponseField>

<ResponseField name="column_count" type="integer">
  The number of columns in the dataset schema.
</ResponseField>

<ResponseField name="organization_id" type="string">
  The organization this dataset belongs to.
</ResponseField>

</Note>
