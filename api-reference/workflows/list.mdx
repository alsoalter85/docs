---
title: "List workflows — GET /workflows"
description: "Retrieve a paginated list of all workflows in your organization. Supports filtering by name and pagination via page and limit query parameters."
---

The List Workflows endpoint returns all workflows available to your organization. Results are paginated — use the `page` and `limit` parameters to navigate through large sets. You can also narrow results with the `search` parameter to match workflows by name.

## Request

```bash
GET https://backend.scalestack.ai/v2/workflows
```

### Query parameters

<ParamField query="page" type="integer">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="integer">
  The number of results per page. Defaults to `20`. Maximum is `100`.
</ParamField>

<ParamField query="search" type="string">
  A search string to filter workflows by name. Partial matches are supported.
</ParamField>

## Example request

```bash
curl https://backend.scalestack.ai/v2/workflows?page=1&limit=20&search=enrichment \
  -H "Authorization: Bearer <api_key>"
```

## Response

Returns a `PaginatedResponse` containing an array of `WorkflowListItem` objects.

<ResponseField name="total" type="integer">
  The total number of workflows matching the query.
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number.
</ResponseField>

<ResponseField name="limit" type="integer">
  The number of results returned per page.
</ResponseField>

<ResponseField name="results" type="array">
  An array of workflow summary objects.

  <Expandable title="WorkflowListItem fields">
    <ResponseField name="id" type="string">
      The unique identifier for the workflow.
    </ResponseField>

    <ResponseField name="name" type="string">
      The display name of the workflow.
    </ResponseField>

    <ResponseField name="status" type="string">
      The current status of the workflow. One of `active`, `draft`, or `archived`.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the workflow was created.
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the last update to the workflow.
    </ResponseField>

    <ResponseField name="organization_id" type="string">
      The ID of the organization that owns the workflow.
    </ResponseField>

    <ResponseField name="folder_id" type="string">
      The ID of the folder the workflow belongs to, if any.
    </ResponseField>
  </Expandable>
</ResponseField>
